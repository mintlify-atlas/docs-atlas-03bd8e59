title: "GET /nodes — List Configured Delivery Nodes"
sidebarTitle: "GET /nodes"
description: "Returns the server-side list of pre-seeded delivery nodes. Empty by default — nodes are managed client-side in the React frontend during normal use."
---

The `/nodes` endpoint returns the list of delivery nodes that have been pre-configured directly in the backend's `main.py` file. In the default installation this list is empty — all sample nodes in the source are commented out — so the endpoint returns an empty array. Nodes are typically created and managed client-side in the React frontend and submitted as part of the `POST /optimize-routes` request body.

This endpoint exists to support server-side seeding scenarios: if an operator uncomments or adds node definitions in `main.py`, those nodes will be returned here and can be used to pre-populate the frontend UI on startup.

## Request

**Method:** `GET`  
**Path:** `/nodes`  
**Auth:** None  
**Parameters:** None

## Response Schema

Returns a JSON array of `Node` objects. Returns `[]` if no nodes are configured server-side.

<ResponseField name="id" type="string" required>
  Unique identifier for the node. The depot must have `id = "0"`. Customer nodes use UUID strings.
</ResponseField>

<ResponseField name="name" type="string" required>
  Human-readable label for the node (e.g. `"Main Depot"`, `"Customer 1"`).
</ResponseField>

<ResponseField name="address" type="string">
  Street address or location description. Optional — used for display purposes only.
</ResponseField>

<ResponseField name="lat" type="float" required>
  Latitude in decimal degrees (WGS 84).
</ResponseField>

<ResponseField name="lng" type="float" required>
  Longitude in decimal degrees (WGS 84).
</ResponseField>

<ResponseField name="nearby_node_id" type="integer | null">
  ID of the nearest EZ Parking station assigned by the preprocessor. `null` before preprocessing runs.
</ResponseField>

<ResponseField name="load" type="integer">
  Demand units this node requires to be delivered. `0` for the depot. Defaults to `0`.
</ResponseField>

<ResponseField name="working_time" type="integer">
  Service time in minutes required at this node. `0` for the depot. Defaults to `0`.
</ResponseField>

```bash cURL
curl http://localhost:8000/nodes
```

<Note>
  In the current implementation, nodes are fully managed client-side. The React frontend lets users geocode addresses and add nodes interactively; those nodes are then passed directly to `POST /optimize-routes`. The `GET /nodes` endpoint is not called as part of the primary optimization flow — it is called on startup to check for any pre-seeded server nodes.
</Note>

## Seeding Nodes Server-Side

To pre-populate nodes, uncomment and edit the `nodes` list in `backend-python/app/main.py`. Each entry must follow the `Node` schema. The first entry should be the depot with `id: "0"`:

```python
nodes = [
    {
        "id": "0",
        "address": "Moakley Library",
        "name": "Main Depot",
        "lat": 42.3568568,
        "lng": -71.0609706
    },
    {
        "id": str(uuid.uuid4()),
        "address": "Timothy J. Toomey, Jr. Park",
        "name": "Customer 1",
        "lat": 42.3665529,
        "lng": -71.0807375,
        "load": 6,
        "working_time": 41
    },
]
```
